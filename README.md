# DANIS.SHOOTER v13

Visual update based on v12. Existing login, menu, Firebase, multiplayer, level flow, shop and UI structure are preserved.

## Visual changes
- Player ships use distinct fighter-jet silhouettes per ship chassis.
- Purchased ship shapes now control the wing silhouette rather than replacing the jet body.
- Enemy silhouettes are varied: interceptor jets, meteors, attack drones, saucers and crystal/alien craft.
- Bosses use six distinct silhouettes instead of a generic square body.
- Ship upgrade levels add stronger visual trails/rings and upgrade-dependent effects.
- Existing ship-specific effects remain active.
